# wm-legacy-crm-sync

> **Progetto di studio / portfolio.** Costruito con IBM webMethods Service Designer (licenza di valutazione, uso non commerciale). Non è in produzione e non rappresenta esperienza su clienti.

Sincronizzazione tra un gestionale legacy (Postgres) e un CRM (mock REST) realizzata su **webMethods Integration Server / Microservices Runtime**, con lo scopo di imparare la piattaforma partendo da un caso d'integrazione già risolto in passato con MuleSoft.

## Stato

In setup (milestone M0). Vedi `CLAUDE.md` per architettura target, regole e stato delle milestone, e `docs/roadmap.md` per il percorso.
